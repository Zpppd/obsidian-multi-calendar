# Obsidian Multi-Calendar Plugin

一个支持多日历档案的 Obsidian 插件。允许用户创建多个独立日历（如"生活日历"、"工作日历"），每个日历拥有独立的笔记路径规则和模板配置，通过切换按钮快速切换。

## 核心功能

- **多日历档案** — 创建、编辑、删除多个日历，每个日历独立配置
- **一键切换** — 日历面板顶部提供箭头切换器，像翻月份一样翻日历
- **独立模板** — 不同日历可以使用不同的模板创建笔记
- **独立路径** — 不同日历的笔记存放在不同的文件夹中

## 技术栈

- Vue 3 (Composition API)
- Pinia (状态管理)
- TypeScript
- luxon (日期处理)
- esbuild (构建)
